# nopCommerce Docker Deployment

This single file documents the full setup and contains every file you need — copy each code block into the file path noted above it.

## Project layout

```
nop-deploy/
├── docker-compose.yml                     # main file (uses `include:`)
└── compose/
    ├── docker-compose.resources.yml       # shared network + volume
    ├── docker-compose.nop.yml             # nop app service
    └── docker-compose.mysql.yml           # mysql service
```

## Build the image

```bash
docker build -t nop:1.0 .
```

## Manual run (without Compose)

```bash
docker network create nopnet
docker run -dit --name nop --network nopnet -p 5000:5000 nop:1.0
```

### Run MySQL

```bash
docker run -dit --name mysql-container \
  -e MYSQL_ROOT_PASSWORD=my-secret-pw \
  --network nopnet \
  -p 3306:3306 \
  -v mysql-data:/var/lib/mysql \
  -d mysql:8.0
```

## Using Docker Compose (recommended)

### File: `docker-compose.yml`

```yaml
include:
  - compose/docker-compose.resources.yml
  - compose/docker-compose.nop.yml
  - compose/docker-compose.mysql.yml
```

### File: `compose/docker-compose.resources.yml`

```yaml
networks:
  nopnet:
    driver: bridge

volumes:
  mysql-data:
```

### File: `compose/docker-compose.nop.yml`

```yaml
services:
  nop:
    image: nop:1.0
    container_name: nop
    build:
      context: .
      dockerfile: Dockerfile
    networks:
      - nopnet
    ports:
      - "5000:5000"
    restart: unless-stopped
```

### File: `compose/docker-compose.mysql.yml`

```yaml
services:
  mysql-container:
    image: mysql:8.0
    container_name: mysql-container
    environment:
      MYSQL_ROOT_PASSWORD: my-secret-pw
    networks:
      - nopnet
    ports:
      - "3306:3306"
    volumes:
      - mysql-data:/var/lib/mysql
    restart: unless-stopped
```

`include:` (Compose v2.20+) merges each listed file's `services`, `networks`, and `volumes` into one project, so this single command brings up everything:

```bash
docker compose up -d --build
```

To stop:

```bash
docker compose down
```

To stop and remove the MySQL data volume too:

```bash
docker compose down -v
```

### Fallback: older Compose versions (no `include:` support)

If your Compose CLI predates `include:` (< v2.20), pass the files directly with `-f` instead of relying on the main file:

```bash
docker compose \
  -f compose/docker-compose.resources.yml \
  -f compose/docker-compose.nop.yml \
  -f compose/docker-compose.mysql.yml \
  up -d --build
```

Check your version with `docker compose version`.

```
http://<ip-address>:5000
```

## Configure MySQL in the nop application

1. On the install screen, select database type **MySQL**.
2. Choose to enter a custom connection string.

Example format:

```
Data Source=sqlServerName;Initial Catalog=dbName;Persist Security Info=True;User ID=root;Password=my-secret-pw
```

Actual connection string to use (replace `localhost` with the VM's IP address if connecting from outside the container network):

```
Data Source=localhost;Port=3306;Initial Catalog=mysql;User ID=root;Password=my-secret-pw;
```
