# Terraform with Azure:

---

## Prerequisites

### 1.1 Install required tools

| Tool | Purpose | Install |
|---|---|---|
| Terraform | IaC tool | https://developer.hashicorp.com/terraform/downloads |
| Azure CLI | Auth + resource management | https://learn.microsoft.com/cli/azure/install-azure-cli |
| Git (optional) | Version control | https://git-scm.com/downloads |

Verify installations:
```bash
terraform -version
az version
```

### Azure requirements

- An active Azure subscription
- Permissions to create resources (Contributor role or higher) and, for Service Principal setup, permissions to create App Registrations in Microsoft Entra ID
- Your **Subscription ID** and **Tenant ID**

Get these via CLI:
```bash
az login
az account show --query id -o tsv        # Subscription ID
az account show --query tenantId -o tsv   # Tenant ID
```

## Authenticate to Azure

Pick **one** method depending on your use case.

### Option A — Azure CLI (recommended for local development)

```bash
az login
az account set --subscription "<subscription-id>"
```

No secrets needed in code — Terraform automatically uses your CLI session.

### Option B — Service Principal with Client Secret (recommended for CI/CD)

Create the Service Principal:
```bash
az account show --query id -o tsv

az ad sp create-for-rbac --name "terraform-sp" \
  --role="Contributor" \
  --scopes="/subscriptions/<subscription-id>"
```

> Windows Git Bash users: prefix with `MSYS_NO_PATHCONV=1` or the `/subscriptions/...` path gets mangled by MSYS path conversion.

```
MSYS_NO_PATHCONV=1 az ad sp create-for-rbac --name "terraform-sp" --role="Contributor" \
  --scopes="/subscriptions/ce2e62f0-7f43-4675-98f5-0735bedf76c9"
```
Output:
```json
{
  "appId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "displayName": "terraform-sp",
  "password": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "tenant": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
}
```

Export as environment variables:
```bash
export ARM_CLIENT_ID="<appId>"
export ARM_CLIENT_SECRET="<password>"
export ARM_SUBSCRIPTION_ID="<subscription-id>"
export ARM_TENANT_ID="<tenant>"
```

### 2.3 Option C — OIDC (recommended for GitHub Actions / Azure DevOps pipelines)

No stored secrets. Create a federated identity credential on your App Registration trusting your pipeline's OIDC token, then:

```bash
export ARM_CLIENT_ID="<appId>"
export ARM_SUBSCRIPTION_ID="<subscription-id>"
export ARM_TENANT_ID="<tenant>"
export ARM_USE_OIDC=true
```

### 2.4 Option D — Managed Identity (when running from an Azure VM/Container/DevOps agent)

```hcl
provider "azurerm" {
  features {}
  use_msi = true
}
```

## 4. Configure the Provider

**providers.tf**
```hcl
terraform {
  required_version = ">= 1.5.0"

  required_providers {
    azurerm = {
      source  = "hashicorp/azurerm"
      version = "~> 3.100"
    }
  }
}

provider "azurerm" {
  features {}
  subscription_id = var.subscription_id
}
```

**variables.tf**
```hcl
variable "subscription_id" {
  description = "Azure Subscription ID"
  type        = string
}

variable "location" {
  description = "Azure region"
  type        = string
  default     = "Central India"
}

variable "resource_group_name" {
  description = "Name of the resource group"
  type        = string
  default     = "rg-demo-network"
}
```

**terraform.tfvars**
```hcl
subscription_id = "ce2e62f0-7f43-4675-98f5-0735bedf76c9"
location         = "Central India"
```

## 5. Sample Resources — RG, VNet, Subnets, NSG

**main.tf**
```hcl
# ---------------------------
# 1. Resource Group
# ---------------------------
resource "azurerm_resource_group" "rg" {
  name     = var.resource_group_name
  location = var.location
}

# ---------------------------
# 2. Virtual Network
# ---------------------------
resource "azurerm_virtual_network" "vnet" {
  name                = "vnet-demo"
  address_space       = ["10.0.0.0/16"]
  location            = azurerm_resource_group.rg.location
  resource_group_name = azurerm_resource_group.rg.name
}

# ---------------------------
# 3. Subnets
# ---------------------------
resource "azurerm_subnet" "subnet_app" {
  name                 = "snet-app"
  resource_group_name  = azurerm_resource_group.rg.name
  virtual_network_name = azurerm_virtual_network.vnet.name
  address_prefixes     = ["10.0.1.0/24"]
}

resource "azurerm_subnet" "subnet_db" {
  name                 = "snet-db"
  resource_group_name  = azurerm_resource_group.rg.name
  virtual_network_name = azurerm_virtual_network.vnet.name
  address_prefixes     = ["10.0.2.0/24"]
}

# ---------------------------
# 4. Network Security Group
# ---------------------------
resource "azurerm_network_security_group" "nsg_app" {
  name                = "nsg-app"
  location            = azurerm_resource_group.rg.location
  resource_group_name = azurerm_resource_group.rg.name

  security_rule {
    name                       = "Allow-SSH"
    priority                   = 100
    direction                  = "Inbound"
    access                     = "Allow"
    protocol                   = "Tcp"
    source_port_range          = "*"
    destination_port_range     = "22"
    source_address_prefix      = "*"
    destination_address_prefix = "*"
  }

  security_rule {
    name                       = "Allow-HTTPS"
    priority                   = 110
    direction                  = "Inbound"
    access                     = "Allow"
    protocol                   = "Tcp"
    source_port_range          = "*"
    destination_port_range     = "443"
    source_address_prefix      = "*"
    destination_address_prefix = "*"
  }
}

# ---------------------------
# 5. Associate NSG with Subnet
# ---------------------------
resource "azurerm_subnet_network_security_group_association" "assoc_app" {
  subnet_id                 = azurerm_subnet.subnet_app.id
  network_security_group_id = azurerm_network_security_group.nsg_app.id
}
```

**outputs.tf**
```hcl
output "resource_group_name" {
  value = azurerm_resource_group.rg.name
}

output "vnet_id" {
  value = azurerm_virtual_network.vnet.id
}

output "subnet_app_id" {
  value = azurerm_subnet.subnet_app.id
}

output "subnet_db_id" {
  value = azurerm_subnet.subnet_db.id
}

output "nsg_app_id" {
  value = azurerm_network_security_group.nsg_app.id
}
```

# Destroy when done
terraform destroy -auto-approve

## 7. (Optional) Remote State — Azure Storage Backend

For team use, store state in Azure Blob Storage instead of locally.

Create the backend resources once (via CLI or a bootstrap Terraform config):
```bash
az group create --name rg-tfstate --location "Central India"

az storage account create \
  --name tfstatestorage$RANDOM \
  --resource-group rg-tfstate \
  --sku Standard_LRS

az storage container create \
  --name tfstate \
  --account-name <storage-account-name>
```

Add to **providers.tf**:
```hcl
terraform {
  backend "azurerm" {
    resource_group_name  = "rg-tfstate"
    storage_account_name = "<storage-account-name>"
    container_name       = "tfstate"
    key                  = "demo.terraform.tfstate"
  }
}
```

Authenticate the backend using the storage access key (or better, `ARM_ACCESS_KEY` env var so it's not in code):
```bash
export ARM_ACCESS_KEY=$(az storage account keys list \
  --account-name <storage-account-name> \
  --resource-group rg-tfstate \
  --query "[0].value" -o tsv)
```

## 8. Quick Reference — Auth Method Cheat Sheet

| Scenario | Method | Key env vars |
|---|---|---|
| Local dev | Azure CLI | none (uses `az login` session) |
| CI/CD (GitHub Actions, Azure DevOps) | OIDC | `ARM_USE_OIDC`, `ARM_CLIENT_ID`, `ARM_TENANT_ID`, `ARM_SUBSCRIPTION_ID` |
| CI/CD (legacy, no OIDC support) | Service Principal + Secret | `ARM_CLIENT_ID`, `ARM_CLIENT_SECRET`, `ARM_TENANT_ID`, `ARM_SUBSCRIPTION_ID` |
| Running on Azure VM/Container | Managed Identity | `use_msi = true` in provider block |

## 9. Common Errors

| Error | Cause | Fix |
|---|---|---|
| `MissingSubscription` | Path got mangled (Windows Git Bash) | Prefix command with `MSYS_NO_PATHCONV=1` |
| `AuthorizationFailed` | SP lacks role assignment | Run `az role assignment create` for the SP |
| `Error building AzureRM Client` | Missing/incorrect env vars | Re-check `ARM_*` variables are exported correctly |
