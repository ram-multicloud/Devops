# Input Variables and Outputs

## Input Variables (`variables.tf`)
Variables allow you to parameterize your Terraform configurations, making them reusable across different environments (e.g., dev, staging, prod) without changing the core code.

### Defining a Variable
```hcl
variable "instance_type" {
  description = "The type of EC2 instance to launch"
  type        = string
  default     = "t2.micro"
}
```

### Using a Variable
You reference a variable using the `var.` prefix.
```hcl
resource "aws_instance" "web" {
  ami           = "ami-12345"
  instance_type = var.instance_type
}
```

### Passing Variable Values
1.  **Default value:** Used if nothing else is provided.
2.  **Command line:** `terraform apply -var="instance_type=t3.small"`
3.  **Variable Definitions File (`.tfvars`):** Create a file named `terraform.tfvars` or `dev.tfvars`.
    ```hcl
    # dev.tfvars
    instance_type = "t3.medium"
    ```
    *(Run with: `terraform apply -var-file="dev.tfvars"`)*

## Output Values (`outputs.tf`)
Outputs are used to extract useful information from your Terraform state after a successful run. This is helpful for finding the IP address of a newly created server or passing data to other Terraform workspaces.

```hcl
output "web_server_public_ip" {
  description = "The public IP address of the web server"
  value       = aws_instance.web.public_ip
}
```
After running `terraform apply`, the console will display:
`web_server_public_ip = "203.0.113.12"`
