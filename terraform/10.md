# Terraform: EC2 User Data vs File Provisioner

## 1. EC2 User Data
`user_data` runs a script automatically when an EC2 instance is launched.

### Example
```hcl
provider "aws" {
  region = "us-east-1"
}

resource "aws_instance" "web" {
  ami           = "ami-xxxxxxxxxxxxxxxxx"
  instance_type = "t2.micro"

  user_data = <<-EOF
    #!/bin/bash
    yum update -y
    yum install -y httpd

    systemctl start httpd
    systemctl enable httpd

    echo "Hello from Terraform User Data" > /var/www/html/index.html
  EOF

  tags = {
    Name = "terraform-web-server"
  }
}
