# Terraform: `refresh`, `graph`, and Type/Fallback Functions

## `terraform refresh`

Reconciles Terraform's state file with the **real** infrastructure — it checks what actually exists in the cloud provider and updates `terraform.tfstate` to match, without changing any real resources.

**Example:** Someone manually resized an EC2 instance in the AWS console (outside Terraform) from `t3.micro` to `t3.large`. Your state file still thinks it's `t3.micro`.

```bash
terraform refresh
```

This updates the state file to record `t3.large` as the current instance type — but it does **not** touch the actual instance. It just fixes Terraform's "memory" of reality.

> Note: `terraform plan` and `apply` do this automatically now, so running `refresh` standalone is rare in modern Terraform — mostly used for inspecting drift.

## `terraform graph`

Outputs the dependency graph (in DOT format) showing the order Terraform will create/modify/destroy resources in.

**Example:**

```bash
terraform graph | dot -Tsvg > graph.svg
```

Given:

```hcl
resource "aws_vpc" "main" { ... }

resource "aws_subnet" "sub" {
  vpc_id = aws_vpc.main.id   # depends on the VPC
}
```

The graph visually shows `aws_subnet.sub → aws_vpc.main`, meaning the VPC must be created first. Useful for debugging "why is X being created after Y" issues.

## Type Conversion & Fallback Functions

| Function | Purpose | Example Input | Output |
|---|---|---|---|
| `tostring(x)` | Converts value to a string | `tostring(5)` | `"5"` |
| `tonumber(x)` | Converts value to a number | `tonumber("5")` | `5` |
| `tolist(x)` | Converts value to an ordered list | `tolist(toset(["b","a"]))` | `["b","a"]` (indexable) |
| `tomap(x)` | Converts value to a map | `tomap({a=1,b=2})` | `{a=1, b=2}` |
| `toset(x)` | Converts value to a set (unique, unordered) | `toset(["a","b","a"])` | `{"a","b"}` |
| `try(x, fallback)` | Evaluates expression; returns fallback if it errors | `try(var.config.port, 8080)` | `8080` if `port` missing |
| `can(x)` | Returns `true`/`false` instead of erroring | `can(cidrhost(var.cidr, 0))` | `false` if invalid CIDR |
| `coalesce(a, b, ...)` | Returns first non-null, non-empty value | `coalesce(null, "", "default")` | `"default"` |
